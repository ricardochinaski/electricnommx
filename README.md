# Electric NOM México ⚡

Suite digital para instalaciones eléctricas conforme a la **NOM-001-SEDE**. Calculadoras técnicas, consulta indexada offline y asistente IA para ingenieros, UVIEs, proyectistas y electricistas en México.

[![GitHub Pages](https://img.shields.io/badge/Sitio%20Web-electricnom.mx-brightgreen)](https://ricardochinaski.github.io/electricnommx)

## Stack

- **App móvil:** Flutter (Dart) — Android / iOS
- **Sitio web:** HTML + Tailwind CSS + Lucide Icons
- **Backend:** Firebase (Auth, Firestore)
- **Monetización:** RevenueCat + AdMob
- **IA:** Google Gemini 2.5 Flash + RAG offline
